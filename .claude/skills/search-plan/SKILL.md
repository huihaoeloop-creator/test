# 检索策略

需求单签完字，下一步不是马上去搜，是先把**搜什么、去哪搜、能搜多少**定下来，
交陈主管过一遍。搜完再发现词错了，几十张图白搜。

跑：

```
python -X utf8 scripts/search_plan.py intake.json --target 40 -o plan.json
```

`--target` 是陈主管给的目标图量。没给就先去要，别自己定。

## 三件事

### 1. 翻译，翻不出来的不猜

陈主管的需求是中文，WGSN、Pinterest、品牌官网都是英文站。脚本查
`LEXICON` 词表；查不到的词进「需补英文」，**不翻**。

一个词翻错，这条检索式下面的所有图全跑偏，而且要到节点 03 风格解构才看得出来。
所以宁可停下来问一句。

补词的正确做法是**把确认后的英文加进 `search_plan.py` 的 `LEXICON`**，
下次同类需求自动生效——不要每次在命令行里临时改。

### 2. 检索式要能真出结果

脚本组的是「修饰词 + 主词 + 季节」，比如 `oversized knitwear AW26`。
这是检索站上真正能出结果的粒度：

- 词堆太多（`oversized drop shoulder mohair cool tone knitwear AW26`）→ 零结果
- 词太少（`knitwear`）→ 几万张，等于没搜

拿到 `--queries` 输出后**自己扫一遍**，明显不通顺的（比如 `rib knit knitwear`
这种同义重复）手动删掉再给陈主管。脚本只负责组合，判断通不通顺是你的活。

### 3. 合规边界是硬的

渠道表写死在 `CHANNELS` 里，`mode` 决定佘吉能做什么：

| 渠道 | mode | 佘吉能做什么 |
|---|---|---|
| 品牌官网 | `auto` | 可自动抓。**仅内部对标**，交付 PPT 必须留 Sources 页注明品牌，绝不能当原创款给客户 |
| Pinterest | `auto-api` | 只走官方 API，保留 pin 链接与作者。不抓网页、不绕登录 |
| WGSN / Fashion Snoops | `manual` | 订阅制且 ToS 禁止抓取。只出选片清单（栏目路径 + 关键词 + 张数），持账号的同事手动导出 |
| Instagram | `off` | 不采集。人工刷到的只记链接，不入素材库 |

这几条**不因为赶工期而放宽**。陈主管要是催，给他的是选片清单和更紧的
Pinterest 配额，不是绕过订阅站。

## 交给陈主管

打印出来的方案要他确认两样：**检索式**和**配额分配**。确认后把
`plan.json` 里的 `approved` 手动改成 `true`，节点 02 才开工——这是权限约束，
不要在脚本里自动置 true。

## 边界

- `--target` 由陈主管定，不自己估。
- 需补英文没清空前不要进节点 02。
- WGSN 的配额是**给人的任务**，不是佘吉的任务；排期时按人工节奏算，别当成能并行跑的。
