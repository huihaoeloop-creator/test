# 生图工具选型

2026-09 调研。**条款会变，签约或大批量跑之前自己再核一遍**，尤其是赔偿条款，
那个按合同走，不按官网宣传走。

## 结论：分工，不是选一个

这条流程里有三件性质不同的活，没有一个工具三件都最好。

| 活 | 用什么 | 为什么 |
|---|---|---|
| 款式主图（模特穿着、正反两张） | **Ideogram**（已有专业版）| 官方 API + 付费档商用授权 + Character Reference 拉正反一致性 |
| 真正进客户交付页的图 | **Adobe Firefly** | 唯一提供 IP 赔偿的一家 |
| 面料花型 | **PatternedAI** | 垂直做无缝循环，可矢量化到 SVG 给印花。没有替代品 |
| 前期概念发散 | Midjourney | 审美上限高，但只能人工 |
| 设计师用中文想 | 即梦 AI | 省一道翻译，授权书可批量下载 |

## 决定性的四条标准

按对这条流程的杀伤力排：

**一、商用授权能不能进客户交付页。** 这条一票否决。

- Firefly：训练数据是 Adobe Stock + 授权/公有领域内容，合格档位给 **IP 赔偿**——
  出事 Adobe 出面。这是别家给不了的。
- Ideogram 付费档：含商用授权，生成物归你。免费档产出公开且商用受限。
- **Leonardo 免费档不能用**：平台保留对生成图的使用、复制、修改、分发权利。
  要用就上付费档。
- 即梦：平台自带授权，能批量下载 PDF 授权书——对交付很实用。

**二、正反一致性。** 这是我们交付形态（一页正反两张）的硬要求，也是整条链最难的一环。

生图模型不保证两次生成是同一件衣服。三条路：
- Ideogram 的 Character Reference（3.0 起，会加价到约 $0.10-0.20/张）
- 先出正面，再用图生图/参考图做背面
- 垂直的 front→back 工具（4fashionai、thenewblack 这类）——**这类我没实测过，
  先小样验证再上量**

不管走哪条，**选片必须成对看，配不上的整对废掉重生**，不能凑合用不同款的正反面。

**三、有没有官方 API。** 决定佘吉能不能自己跑。

| 有 | 没有 |
|---|---|
| Ideogram、Firefly、Leonardo、Recraft | **Midjourney** |

Midjourney 的第三方中转和 Discord self-bot 同时违反两家 ToS，封号是真的。
**给账号也不能让它变合规**——只能人工粘贴。

即梦的 API 走火山方舟，接入成本另算，先按人工用。

**四、单张成本。** Ideogram V4 约 $0.03（Turbo）/ $0.06（默认）/ $0.10（Quality）。
一单 20 款 × 正反 2 张 × 选片比 3:1 = 120 张，默认档约 $7。这个量级下成本不是瓶颈，
**别为省钱牺牲授权干净度**。

## 其他几个，为什么没进主力

- **Stable Diffusion 自建**：唯一能完全离线、数据不出公司的选项。要 GPU 和运维，
  而且各版本权重商用条款不一样（SDXL 和 SD3 不同），上之前逐个核。
  数据敏感度真的高到这一步时再考虑。
- **Recraft**：SVG 矢量导出是它的强项，但我们的交付是位图款式图，用不上。
  真要做印花矢量化，PatternedAI 那条更对口。
- **DALL·E 3 / ChatGPT Image**：便利，但服装细节可控性不如上面几家。
- **Krea、Fashion Diffusion、Myth AI**：Fashion Diffusion 有 sketch-to-render，
  手绘稿转渲染这个场景对口，但每月 $12 只给 50 张额度，比同价位少很多——
  **先用免费额度试，别直接买**。

## 落地顺序

1. **先用已有的 Ideogram 专业版跑一轮**，验证 prompt 和正反一致性到底什么水平。
   这一步不花新钱。
2. 结果能用 → 交付页那批图再用 Firefly 重出一遍，拿赔偿条款兜底。
3. 有印花需求再上 PatternedAI。
4. 以上都不够 → 再谈自建。

**别一次买五个工具。** 先用一个跑通，缺什么再补什么。
